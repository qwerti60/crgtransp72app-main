# Руководство менеджеру — админка CRG Transp72

Пошаговая инструкция для сотрудника, который модерирует пользователей и объявления в мобильном приложении «CRG Transp72». Без технических терминов.

**Сценарии приложения (сделки, поиск, чаты):** [app_scenarios_ru.md](./app_scenarios_ru.md) — для понимания, как действия в админке влияют на выдачу и сделки.

---

## 1. Для чего нужна админка

Через браузер вы:

- проверяете и одобряете **новых пользователей**;
- публикуете **объявления исполнителей** (грузоперевозки, спецтехника, грузчики);
- смотрите **заявки заказчиков**, отклики и предложения;
- проверяете **подписку исполнителя**, **историю оплат** и **доходы по сделкам**;
- смотрите **выручку от подписок** и сводную статистику на дашборде;
- обрабатываете **жалобы** и переписку в **поддержке**;
- настраиваете **пакеты подписки**, **промокоды** и **поднятие объявлений**;
- выставляете **счета юрлицам**, смотрите **автомодерацию** и **выгрузки для бухгалтерии**;
- редактируете **справочники** (города, виды техники и т.д.);
- отправляете **рассылку** (e-mail и/или push) группам пользователей;
- меняете **цену и срок подписки** исполнителей и **пароль/e-mail** своей учётки в настройках.

Заказчики и исполнители работают в **мобильном приложении**. Админка — ваш рабочий стол в офисе.

## 2. Вход в систему

1. Откройте страницу входа (адрес выдаёт администратор сайта; локально: `http://127.0.0.1:8080/admin-web/login.php`).
2. Введите **логин** и **пароль**.
3. После входа слева — меню разделов, справа — содержимое.

### Первый вход

1. Войдите с учётными данными, которые выдал администратор (по умолчанию после установки: логин `admin`, пароль `ChangeMe_Admin1!`).
2. Откройте **Настройки** → укажите **e-mail** → **Сохранить e-mail**.
3. В том же разделе **смените пароль** (новый — не короче 10 символов). После смены нужно войти снова.

Без указанного e-mail **восстановление пароля по коду не сработает**.

### Забыли пароль

На странице входа — ссылка **«Забыли пароль?»**:

1. Введите **логин** → **Выслать код**.
2. Откройте письмо (код действует около 15 минут).
3. Введите логин, **код** и **новый пароль** на втором шаге.

E-mail для кода берётся из **Настройки** (если вы уже входили) или задаётся администратором сервера.

Внизу меню после входа: **Руководство** (эта инструкция), **Техническое** (для IT) и **Выйти**.

## 3. Меню — что где искать

| Раздел | Зачем нужен |
|--------|-------------|
| **Статистика** | Сводка, **выручка**, **воронка**, подписки, отклики, сделки |
| **Города** | Список городов; **координаты lat/lng** — для «Рядом со мной» |
| **Вид техники** | Категории для спецтехники (с картинками) |
| **Грузоподъёмность** | Варианты «до 5 т.», «до 20 т.» и т.п. |
| **Вид кузова** | Тент, фургон, бортовой и др. |
| **Пользователи** | Все зарегистрированные; галочка **«Проверен»** у исполнителей |
| **Объявления исполнителей** | То, что исполнители выставляют «я готов работать» |
| **Заявки заказчиков** | То, что заказчики ищут «мне нужен перевозчик / техника / грузчики» |
| **Рассылка** | Массовые e-mail и push выбранной аудитории |
| **Настройки** | Legacy-тариф, e-mail и пароль вашей учётки |
| **Пакеты** | Тарифы подписки: месяц / квартал / год (основные цены в приложении) |
| **Промокоды** | Скидки на подписку |
| **Поднятие** | Цены «в топ» объявления на 24 и 72 часа |
| **Поддержка** | Обращения пользователей, **жалобы**, просмотр чата по сделке |
| **Счета B2B** | Заявки юрлиц на оплату подписки по счёту |
| **Автомодерация** | Стоп-слова; журнал автоотклонений объявлений |
| **Экспорт CSV** | Выгрузка пользователей, оплат и сделок для бухгалтерии |

**Красная точка** в меню: **Объявления исполнителей** (на проверке), **Поддержка** (новые обращения), **Счета B2B** (активные заявки).

## 4. Статистика

Раздел **Статистика** — сводная панель по приложению (обновляется при каждом открытии страницы). Это первая страница после входа.

### Период для выручки и подписок

Вверху страницы — выбор **периода**:

| Вариант | Что показывает |
|---------|----------------|
| **Сегодня** | Оплаты и оборот за текущий день |
| **7 дней** | За последнюю неделю |
| **30 дней** | За последний месяц (по умолчанию) |
| **Всё время** | Все записи в журнале оплат |
| **Свой период** | Даты «с» и «по» |

Период влияет на блок **«Выручка и оборот»**, карточки оплат подписок, графики по дням и таблицу последних платежей. Общие KPI (пользователи, объявления, отзывы) — без привязки к периоду.

### Выручка и оборот (синий блок)

| Показатель | Смысл |
|------------|--------|
| **Оплаты подписок** | Реальная сумма, которую исполнители заплатили за доступ (из журнала оплат) |
| **Оборот сделок (GMV)** | Сумма **выполненных** заказов в приложении за период (доход исполнителей по сделкам) |
| **Суммарно** | Подписки + оборот сделок |
| **Подписки за всё время** | Показывается при выборе не «всё время» — для сравнения с периодом |

### Подписки за выбранный период

Карточки под синим блоком:

| Показатель | Смысл |
|------------|--------|
| **Выручка подписок** | Сумма оплат за период |
| **Платежей** | Сколько раз оплатили |
| **Уникальных плательщиков** | Сколько разных исполнителей платили |
| **Новые подписки** | Первый платёж пользователя (впервые оформил доступ) |
| **Продления** | Повторные оплаты (уже платил раньше) |
| **Средний чек** | Средняя сумма одного платежа |

Если журнал оплат на сервере ещё не настроен, вместо сумм будет подсказка — обратитесь к техническому администратору (миграция `subscription_payment_log`).

### Подписки — срез «на сейчас»

Три таблицы с текущим состоянием:

| Показатель | Смысл |
|------------|--------|
| **Активные** | Подписка действует сегодня |
| **Истекшие** | Срок закончился |
| **Заканчиваются за 7 дней** | Скоро нужно продлить — можно напомнить через **Рассылку** |
| **Истекли в выбранном периоде** | Сколько подписок закончилось в выбранных датах |
| **Продлевали более 1 раза** | Лояльные исполнители |
| **Не продлили** | Была подписка, срок истёк, не продлили |
| **Без подписки** | Исполнители, которые никогда не оформляли доступ |
| **Конверсия в подписку** | Доля исполнителей, которые хотя бы раз подписывались |
| **Оценка MRR** | Грубая оценка: число активных × текущая цена тарифа |

### Графики и последние оплаты

- **Оплаты подписок по дням** — столбики по сумме; при наведении видно число платежей, новых и продлений.
- **Последние оплаты** — таблица: дата, исполнитель, сумма, тип (**Новая** / **Продление**), ссылка на карточку пользователя.
- **Оборот сделок по дням** — сумма выполненных заказов по дням.

### Остальные блоки

**Карточки KPI:** пользователи, регистрации за 30 дней, очередь модерации, объявления и заявки, подписки (активные/истекшие), отклики, отзывы, сделки.

**Таблицы и диаграммы:**

| Блок | Что показывает |
|------|----------------|
| Пользователи по ролям | Заказчики, грузоперевозчики, спецтехника, грузчики |
| Топ городов | Где больше всего зарегистрированных |
| Регистрации за 30 дней | Динамика новых пользователей |
| Объявления исполнителей | Всего / опубликовано / на проверке по типам |
| Заявки заказчиков | Всего и активные (ещё не истёк срок) |
| Отклики и предложения | Активность на заявках и объявлениях, средние цены |
| Отзывы | Количество, средняя оценка, распределение звёзд |
| Сделки | Всего / выполняются / выполнены / отменены |

### Воронка (P2)

Отдельный блок **«Воронка»** — цепочка шагов с числами:

1. Регистрации пользователей  
2. Опубликованные объявления исполнителей  
3. Отклики и предложения  
4. Сделки (`ordersglobal`)  
5. Оплаты подписки  

Помогает увидеть, на каком этапе «проседает» воронка (много регистраций, мало сделок и т.д.).

Ссылки внизу блоков ведут в **Настройки** (тариф), **Пользователи**, **Рассылку**, **Объявления** — если есть что модерировать или напомнить об оплате.

## 5. Рассылка

Раздел **Рассылка** — отдельная страница для сообщений пользователям приложения. Можно отправить **e-mail**, **push в приложение** или оба канала сразу.

### Кому можно отправить

| Вариант | Когда использовать |
|---------|-------------------|
| **Все пользователи** | Общее объявление для всех |
| **По городам** | Новости или акции в конкретных городах |
| **Подписка: осталось 3 дня** | Напоминание исполнителям продлить доступ |
| **Подписка истекла** | Приглашение снова оформить подписку |
| **По роли** | Только заказчикам или только исполнителям |
| **Выбранные ID** | Точечное сообщение (ID — в разделе «Пользователи») |

### Как отправить

1. Выберите **аудиторию** и при необходимости города, роли или список ID.
2. Заполните **тему** (заголовок письма и push) и **текст** сообщения.
3. Отметьте каналы: **E-mail** и/или **Push в приложение**.
4. Нажмите **Проверить выборку** — система покажет, сколько человек попадёт в рассылку.
5. Нажмите **Отправить** и подтвердите действие.

**Важно:**

- Push приходит только тем, у кого есть токен в приложении; без него пользователь будет пропущен по push, но может получить e-mail.
- Текст push короче полного письма (около 240 символов); полный текст — в e-mail.
- За один раз — не более **2000** получателей; для больших списков разбейте рассылку по городам или ролям.
- Перед массовой рассылкой всегда используйте **Проверить выборку**.

## 6. Настройки

Раздел **Настройки** объединяет настройки **вашей учётки** и **тарифа подписки** для исполнителей.

### Ваша учётная запись

| Действие | Как |
|----------|-----|
| **E-mail** | Укажите рабочий адрес и нажмите **Сохранить e-mail** — нужен для восстановления пароля |
| **Смена пароля** | Знаете текущий пароль → блок «Смена пароля» → после сохранения войдите снова |
| **Забыли пароль** | Страница входа → **Забыли пароль?** → код на e-mail (e-mail должен быть в настройках) |
| **Первый вход после установки** | Войти → **Настройки** → e-mail → сменить пароль |

Новый пароль — **не короче 10 символов**. Код из письма действует **около 15 минут** (точный срок настраивает администратор сервера).

### Тариф подписки исполнителя

> **Важно:** основные цены для приложения задаются в разделах **Пакеты** и **Промокоды**. Раздел **Настройки** — legacy-тариф (один пакет «месяц»), используется как запасной вариант.

| Поле | Что меняет |
|------|------------|
| **Цена, ₽** | Сумма legacy-тарифа (если пакеты недоступны) |
| **Срок подписки, дней** | Срок продления legacy-тарифа |

После **Сохранить тариф** новые значения подхватывает API. Уже оплаченные подписки не пересчитываются.

На карточке исполнителя в блоке «Подписка» есть ссылка **Изменить в настройках**.

### Пакеты и промокоды (P1)

**Пакеты** — несколько тарифов (месяц / квартал / год): название, число дней, цена, порядок в списке, активен/нет.

**Промокоды** — код скидки (процент или фиксированная сумма), срок действия, лимит использований.

Исполнитель видит пакеты на экране **«Оформление подписки»** в приложении.

## 7. Пользователи

### Роли

| Роль | Кто это |
|------|---------|
| Заказчик | Размещает заявки, ищет исполнителей |
| Грузоперевозчик | Перевозит грузы |
| Спецтехника | Экскаватор, кран и т.д. |
| Грузчики | Бригады грузчиков |

### Статус проверки

| Статус | Что значит |
|--------|------------|
| **На проверке** | Пользователь зарегистрировался, но ещё не одобрен — ограниченный доступ |
| **Одобрен** | Может полноценно пользоваться приложением |

**Что делать:** откройте карточку пользователя → проверьте ФИО, телефон, e-mail, город → если всё в порядке, поставьте **Одобрен** и сохраните. На списке можно нажать **Одобрить** без входа в карточку.

### Верификация «Проверен» (P2)

Только для **исполнителей**. Галочка **«Проверен»** на карточке пользователя — после проверки документов (паспорт, СТС и т.д. вне приложения).

**В приложении** у заказчика на карточке исполнителя появляется бейдж **«Проверен»**. Это не заменяет модерацию объявления — только доверие к человеку.

### Подписка (только исполнители)

В списке и на карточке исполнителя видно:

| Статус | Значение |
|--------|----------|
| **Активна** | Исполнитель оплатил доступ, может работать в приложении |
| **Истекла** | Срок закончился — нужно продлить в приложении |
| **Не оформлена** | Ещё не платил |

На карточке также: **до какой даты** действует, **сколько раз оплачивал**. Заказчикам колонка «Подписка» не показывается — им она не нужна.

В списке пользователей у исполнителя есть ссылка **«Финансы»** — открывает карточку с блоком финансов.

### Финансы исполнителя (на карточке пользователя)

Блок **«Финансы пользователя»** внизу карточки исполнителя (якорь `#user-finances`):

| Раздел | Что показывает |
|--------|----------------|
| **Оплаты подписки** | Все платежи: дата, сумма, срок продления, ID платежа |
| **Доходы** | Выполненные сделки за выбранный период: сумма, заказчик, описание |

**Период доходов** (выпадающий список): сегодня, 7 дней, 30 дней или свой период с датами.

**Как смотреть историю оплат конкретного исполнителя:** Пользователи → найти исполнителя → **Финансы** (или открыть карточку и прокрутить до блока «Финансы»). Из **Статистики** в таблице последних оплат — стрелка **→** на карточку.

### Отзывы

На карточке пользователя:

- у **исполнителя** — отзывы от заказчиков (оценка звёздами и текст);
- у **заказчика** — отзывы от исполнителей.

Помогает оценить надёжность перед спорной ситуацией.

## 8. Объявления исполнителей

Три типа (переключатель вверху списка):

- **Грузоперевозки** — машины, перевозки;
- **Спецтехника** — экскаваторы, краны;
- **Грузчики** — бригады.

### Модерация

| Статус | Что видят в приложении |
|--------|-------------------------|
| **На проверке** | Объявление **не показывается** заказчикам |
| **Опубликовано** | Видно всем в приложении |

**Ваши действия:** откройте объявление → посмотрите текст, фото и документы (клик по миниатюре — увеличить) → если всё корректно, нажмите **Одобрить и опубликовать**.

Если что-то не так — заполните поле **«Что нужно исправить»** и нажмите **Отклонить и уведомить**. Исполнитель получит **письмо на e-mail** и **push в приложение** (если есть e-mail и/или пользователь заходил в приложение). Объявление останется **на проверке**.

**Автомодерация (P3):** часть объявлений отклоняется **автоматически** при создании — без фото, со стоп-словом. Смотрите раздел **Автомодерация** (журнал) и очередь **Объявления исполнителей**. Дубли опубликованных объявлений попадают в очередь на ручную проверку.

Чтобы снять с публикации — **Снять с публикации** на уже опубликованном объявлении.

### На карточке объявления также

- **Предложения заказчиков** — кто из заказчиков предложил работу (только у опубликованных);
- **Отзывы об исполнителе** — репутация владельца объявления.

---

## 9. Заявки заказчиков

Три типа заявок — как в приложении:

- перевозки;
- спецтехника;
- грузчики.

Заявки **не требуют отдельной модерации** — появляются в приложении сразу.

На карточке заявки:

- описание и фото;
- **Отклики исполнителей** — кто откликнулся, цена, статус (активный / принят);
- **Отзывы о заказчике**.

---

## 10. Справочники и города

**Города** — добавление, переименование, удаление (удалить можно только если город нигде не используется).

Для работы **«Рядом со мной»** в приложении у города должны быть заполнены **координаты** (широта и долгота). Без них геопоиск по радиусу для этого города не сработает.

**Справочники** (вид техники, грузоподъёмность, вид кузова) — добавляйте пункты с названием и при необходимости картинкой. При переименовании система может предложить обновить старые объявления — согласуйтесь, если нужно сохранить единообразие в приложении.

## 10.1. Поддержка и жалобы (P1)

Раздел **Поддержка** — обращения пользователей из приложения.

| Фильтр | Содержимое |
|--------|------------|
| Все | Любые тикеты |
| **Жалобы** | Жалобы на объявление или спор по сделке |

**Жалоба на объявление** — пользователь пожаловался с карточки исполнителя.  
**Спор по сделке** — жалоба из чата активной сделки.

На карточке тикета можно ответить пользователю. Для жалоб по сделке — кнопка **«Открыть deal-чат»** (только просмотр переписки заказчика и исполнителя, без возможности писать от их имени).

## 10.2. Поднятие объявлений (P2)

Раздел **Поднятие** — тарифы, которые исполнитель покупает в приложении (**Мои объявления** → иконка «в топ»):

| Тариф | Обычно |
|-------|--------|
| 24 часа | Краткое поднятие в выдаче |
| 72 часа | Более длинное |

После оплаты объявление **выше** в поиске у заказчиков до окончания срока. Цены редактируются на этой странице.

## 10.3. Счета для юрлиц — B2B (P3)

Раздел **Счета B2B** — заявки исполнителей-**организаций**, которые не платят картой, а просят счёт на оплату.

| Статус | Что делать |
|--------|------------|
| **Запрошен** | Проверить реквизиты (ИНН, название) → ввести **№ счёта** → **Выставить** |
| **Счёт выставлен** | После поступления оплаты в банке → **Оплачен** (подписка продлится автоматически) |
| **Оплачен** | Архив, ничего не требуется |
| **Отменён** | Заявка закрыта без оплаты |

PDF-счёт формируется **вне** системы (в 1С или вручную) — в админке фиксируется только номер и статус.

## 10.4. Автомодерация (P3)

Раздел **Автомодерация**:

- **Стоп-слова** — фразы, при которых объявление **сразу отклоняется** (push + e-mail исполнителю).
- **Журнал** — последние срабатывания: какое правило, какое объявление.

Правила при **создании** объявления:

| Правило | Результат |
|---------|-----------|
| Стоп-слово в тексте | Автоотклонение |
| Нет ни одного фото | Автоотклонение |
| Дубль уже опубликованного | Очередь на ручную проверку |

Ручная модерация в **Объявления исполнителей** по-прежнему нужна для остальных случаев.

## 11. Поиск в приложении — что важно модератору

Пользователи ищут исполнителей и заявки **в мобильном приложении**. В веб-админке **нет** кнопки «найти как в приложении» — вы влияете на выдачу через модерацию и справочники.

### Кто что ищет

| Роль в приложении | Ищет | Где в приложении |
|-------------------|------|------------------|
| **Заказчик** | исполнителей (техника, перевозки, грузчики) | «Заказы» → «Найти исполнителей», раздел «Услуги» |
| **Исполнитель** | заявки заказчиков | «Заявки» → «Найти заявки» |

Строка поиска вроде «экскаватор в Тюмени» работает **без** обязательного выбора города и услуги — приложение само распознаёт город и категорию из текста.

### Почему объявление не попадает в поиск

| Ситуация | Что проверить в админке |
|----------|-------------------------|
| Исполнитель «не виден в поиске» | **Объявления исполнителей** → статус **Опубликовано** (`flag`); **Пользователи** → **Подписка** активна |
| Заявка заказчика «пропала из поиска» | **Заявки заказчиков** → срок действия (`enddatez`) — просроченные не показываются |
| «Ничего не находит» по городу или услуге | **Города** и **Справочники** — название в объявлении должно **точно** совпадать со справочником (например «Тюмень», не «г. Тюмень») |
| Пользователь не одобрен | **Пользователи** → статус **Одобрен** |
| Объявление уже в работе | Если отклик принят — объявление скрывается из поиска (это нормально) |

### Быстрый подбор из «Мои объявления»

Заказчик нажимает **«Найти исполнителей»** у своей заявки — приложение подставляет город и категорию. Исполнитель — **«Найти заявки»** у своего объявления. Если результат пустой, приложение открывает **полную форму поиска** — пользователь может изменить фильтры.

### Поиск внутри админки — это другое

Поле «Поиск» на страницах **Пользователи**, **Объявления**, **Заявки**, **Города** ищет только **внутри списка админки**, не в приложении.

### Когда звать технического администратора

- Поиск в приложении **вообще не работает** (ошибка, пустой экран у всех).
- После проверки модерации и справочников объявление **должно** быть в выдаче, но его нет.

Подробности для разработчика — раздел «Техническое» → [search_logic_ru.md](./search_logic_ru.md).

## 12. Типичные задачи — шпаргалка

| Ситуация | Что сделать |
|----------|-------------|
| Общая картина по приложению | **Статистика** (первая страница после входа) |
| Сколько заработали на подписках | **Статистика** → блок «Выручка и оборот» → выбрать период |
| Новые vs продления подписок | **Статистика** → карточки «Новые подписки» / «Продления» |
| Кто не продлил подписку | **Статистика** → «Не продлили»; **Рассылка** → «Подписка истекла» |
| История оплат одного исполнителя | **Пользователи** → карточка → **Финансы** |
| Доход исполнителя по сделкам | **Пользователи** → карточка → **Финансы** → период «Доходы» |
| Новый пользователь «висит» на проверке | Пользователи → карточка → **Одобрен** |
| Исполнитель жалуется, что объявление не видно | Объявления исполнителей → **Опубликовать**; проверить **Подписку** (§11) |
| Заказчик: «не нахожу исполнителей» | §11: опубликованные объявления исполнителей, город/услуга в справочниках, срок заявки |
| Текстовый поиск «экскаватор в Тюмени» пустой | Убедиться, что в справочниках есть «Тюмень» и нужная категория; объявления опубликованы |
| Выполненный заказ всё ещё в поиске исполнителей | Нормально до деплоя API; после — заявка скрыта (`ordersglobal` выполнен/выполняется); см. [app_scenarios_ru.md](./app_scenarios_ru.md) §4, §7 |
| Объявление с ошибками в документах или тексте | Карточка → **Отклонить и уведомить** (e-mail + push) |
| Нужно понять, платил ли исполнитель | **Пользователи** → карточка → блок **Подписка** или **Финансы** (журнал оплат) |
| Заказчик спрашивает, кто откликнулся | Заявки заказчиков → карточка → **Отклики исполнителей** |
| Жалоба на исполнителя / заказчика | Карточка пользователя → **Отзывы**; при необходимости снять объявление с публикации |
| Изменить цену подписки исполнителя | **Пакеты** (основное) или **Настройки** (legacy-тариф) |
| Сменить свой пароль в админке | **Настройки** → смена пароля |
| Первый вход после установки | Войти → **Настройки** → e-mail → сменить пароль |
| Забыли пароль админки | Страница входа → **Забыли пароль?** → код на e-mail |
| Напомнить об окончании подписки | **Рассылка** → «Подписка: осталось 3 дня» → проверить выборку → отправить |
| Сообщение только исполнителям одного города | **Рассылка** → «По городам» → выбрать город(а) |
| Жалоба из приложения | **Поддержка** → фильтр «Жалобы» → ответ / просмотр deal-чата |
| Включить геопоиск «рядом» | **Города** → координаты lat/lng у нужного города |
| Изменить цены подписки (пакеты) | **Пакеты** / **Промокоды** |
| Поднять объявление платно | **Поднятие** → тарифы 24/72 ч; исполнитель платит в приложении |
| Отметить исполнителя «Проверен» | **Пользователи** → карточка → галочка **Проверен** |
| Счёт для юрлица | **Счета B2B** → выставить № → после оплаты **Оплачен** |
| Стоп-слово в объявлениях | **Автомодерация** → добавить слово |
| Выгрузка для бухгалтерии | **Экспорт CSV** → users / payments / deals |
| Проверить всё после обновления | См. [testing_guide_ru.md](./testing_guide_ru.md) |

## 13. Важно помнить

- **Не удаляйте** пользователя или объявление без необходимости — удаление необратимо вместе со связанными данными.
- **Не публикуйте** объявления с сомнительными документами или фото — лучше запросить уточнение у исполнителя по телефону из карточки.
- **Подписку** продлевает исполнитель через приложение (картой или **запросом счёта** для юрлица); в админке вы **смотрите** статус, **историю платежей**, **выручку**, **Пакеты/Промокоды**, **Счета B2B**.
- После **первого входа** обязательно укажите **e-mail** и **смените пароль** в «Настройках».
- Вопросы по **неполадкам сайта, паролям, серверу** — к техническому администратору (см. «Техническое» в меню).
