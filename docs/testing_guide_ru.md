## 1. Что нужно для проверки

| Что | Зачем |
|-----|--------|
| **Смартфон** с установленным приложением | Геолокация и push на реальном устройстве надёжнее, чем в эмуляторе |
| **Два аккаунта** | Заказчик и исполнитель (лучше на разных телефонах) |
| **Доступ в админку** | Проверка жалоб, модерации, счетов, CSV |
| **Обновлённый сервер** | Миграции P1 → P2 → P3 и файлы из архивов `dist/p*_deploy_*.zip` |

### Сборка приложения (разработчик)

```bash
cd /path/to/crgtransp72app-main-main
flutter pub get
flutter run
```

На телефоне разрешите **геолокацию** и **уведомления**.

## 2. Быстрый прогон (~30 минут)

Если времени мало — по одному пункту из каждого блока:

| # | Где | Действие | Ожидание |
|---|-----|----------|----------|
| 1 | Приложение, заказчик | Поиск → «Рядом со мной», радиус 30 км | Список с расстоянием |
| 2 | Приложение | «Пожаловаться» на объявление | Заявка в админке → Поддержка |
| 3 | Приложение, исполнитель | Оформление подписки → выбор пакета | Цены как в админке «Пакеты» |
| 4 | Приложение | Первый вход нового пользователя | 3 экрана онбординга |
| 5 | Приложение, исполнитель | «Мои объявления» → поднять в топ | В поиске выше остальных |
| 6 | Приложение | Сделка → исполнитель «В пути» | Push у заказчика |
| 7 | Приложение, исполнитель | Новое объявление **без фото** | Автоотклонение (P3) |
| 8 | Админка | Экспорт CSV → payments | Файл открывается в Excel |

## 3. P1 — гео, жалобы, push, пакеты

### 3.1 Геопоиск «рядом со мной»

**В админке:** **Города** → у города (например Тюмень) заполнены координаты lat/lng.

**В приложении (заказчик):**

1. Поиск исполнителей.
2. Включить **«Рядом со мной»**.
3. Выбрать радиус (10 / 30 / 50 км).

**Ожидание:** объявления с расстоянием; ближние выше при сортировке по удалённости.

### 3.2 Жалобы

**Из карточки объявления:** «Пожаловаться» → текст → отправить.

**Из чата сделки:** «Пожаловаться» → описание спора.

**В админке:** **Поддержка** → фильтр **Жалобы** → тикет в списке → при споре по сделке можно открыть **deal-чат** (только просмотр).

### 3.3 Push по сделке

1. Сверните приложение получателя (или заблокируйте экран).
2. С другого аккаунта: отклик, принятие, «начать выполнение», «в пути».

**Ожидание:** уведомление в шторке.

**Если push нет:** выйти и войти в приложение (обновится FCM-токен); проверить разрешения уведомлений в настройках телефона.

### 3.4 Пакеты подписки и промокоды

**В админке:** **Пакеты**, **Промокоды** — три пакета (месяц / квартал / год), тестовый промокод.

**В приложении (исполнитель):** **Оформление подписки** → выбор пакета → промокод → оплата (тестовая карта, если включена).

**Ожидание:** подписка активна, дата окончания обновилась; в **Статистика** появилась оплата.

## 4. P2 — онбординг, топ, верификация, шаблоны, «в пути», воронка

### 4.1 Онбординг

Новый пользователь или сброс флага онбординга (debug) → **3 экрана** → «Пропустить» или «Начать работу» → при повторном входе не показывается.

### 4.2 Поднятие объявления в топ

**Админка:** **Поднятие** — тарифы 24 ч / 72 ч (например 199 / 399 ₽).

**Приложение (исполнитель):** **Мои объявления** → иконка **стрелки вверх** у опубликованного объявления → оплата.

**Проверка:** в поиске у **заказчика** это объявление **выше** остальных в той же категории.

### 4.3 Верификация «Проверен»

**Админка:** **Пользователи** → исполнитель → галочка **«Проверен»** → сохранить.

**Приложение (заказчик):** в поиске на карточке — бейдж **«Проверен»**.

### 4.4 Шаблон заявки «как прошлую»

**Приложение (заказчик):** **Мои объявления** → иконка **копии** → выбрать прошлую заявку → дубликат в списке.

### 4.5 Статус «В пути» + ETA

1. Довести сделку до «выполняется».
2. **Исполнитель:** кнопка **«В пути»**, указать время прибытия.
3. **Заказчик:** push «Исполнитель в пути», в карточке сделки — статус и ETA.

### 4.6 Воронка в статистике

**Админка:** **Статистика** → блок **«Воронка (P2)»** — цепочка: регистрации → объявления → отклики → сделки → оплата подписки (числа без ошибок).

## 5. P3 — B2B-счета, автомодерация, CSV

### 5.1 Счёт для юридического лица

**Условие:** исполнитель зарегистрирован как **организация** (ИНН, название фирмы в профиле).

**Приложение:** **Оформление подписки** → **«Запросить счёт (юр. лицо)»** → сообщение «Заявка принята».

**Админка → Счета B2B:**

1. Заявка в статусе **«Запрошен»**.
2. Ввести **№ счёта** → **Выставить** → **«Счёт выставлен»**.
3. После оплаты по банку → **Оплачен** → подписка продлена.

**Проверка:** у исполнителя активная подписка; в журнале оплат способ `invoice`.

### 5.2 Автомодерация объявлений

**Админка → Автомодерация:** список стоп-слов, журнал срабатываний.

| Тест | Как | Ожидание |
|------|-----|----------|
| Стоп-слово | В новом объявлении написать слово из списка (например «казино») | Автоотклонение, push/письмо |
| Без фото | Создать объявление без единого фото | Автоотклонение |
| Дубль | Скопировать уже **опубликованное** своё объявление | Остаётся «на проверке» в очереди модерации |

Правила срабатывают при **создании** объявления, не при редактировании.

### 5.3 Экспорт CSV

**Админка → Экспорт CSV:**

| Файл | Содержимое |
|------|------------|
| `users.csv` | Пользователи (до 10 000) |
| `payments.csv` | Оплаты подписки за период |
| `deals.csv` | Сделки за период |

**Ожидание:** UTF-8 с BOM, разделитель `;`, кириллица читается в Excel.

## 6. Проверка из админки (сводка)

| Раздел | Что проверить |
|--------|----------------|
| **Города** | Координаты для геопоиска |
| **Пакеты / Промокоды** | Цены совпадают с приложением |
| **Поднятие** | Тарифы 24/72 ч |
| **Поддержка** | Жалобы, deal-чат |
| **Пользователи** | «Проверен», подписка, финансы |
| **Объявления исполнителей** | Очередь модерации, одобрение/отклонение |
| **Статистика** | Выручка, воронка |
| **Счета B2B** | Цикл заявка → счёт → оплата |
| **Автомодерация** | Стоп-слова, журнал |
| **Экспорт CSV** | Три типа выгрузки |

**Красная точка** в меню: объявления на проверке или новые обращения в поддержку / активные счета B2B.

## 7. Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| Старые экраны, нет новых кнопок | Пересобрать приложение (`flutter run` / release) |
| Ошибки API, пустые ответы | Залиты ли файлы из zip на сервер; не затёрт ли `databd.php` |
| Нет разделов P3 в админке | Миграция `migrate_p3_features.sql` |
| Гео не работает | Координаты города; разрешение GPS на телефоне |
| Push не приходят | FCM-токен — перелогин; приложение в фоне; `service_account.json` на сервере |
| «Запросить счёт» недоступно | Аккаунт должен быть **юр. лицо** (`statNum=1`) |
| Автомодерация не срабатывает | Миграция P3; создавать **новое** объявление, не редактировать старое |
