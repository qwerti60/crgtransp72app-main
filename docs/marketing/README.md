# Маркетинг-план

## Открыть в браузере

```bash
open docs/marketing/marketing_plan.html
```

Или двойной клик по файлу.

## Скачать PDF

1. Откройте `marketing_plan.html` в Chrome
2. Нажмите **«Скачать PDF»** вверху или `Cmd+P` / `Ctrl+P`
3. Принтер: **«Сохранить как PDF»**
4. Включите **«Фоновая графика»**

## Содержание

- Цели и этапы (12 месяцев)
- Аудитория, стратегия 90 дней
- Бюджеты: минимум / базовый / агрессивный
- Прогноз заказчиков и исполнителей
- Экономика и KPI
- **Веб-админка** — статистика, рассылка, поддержка, модерация
- План первого месяца
