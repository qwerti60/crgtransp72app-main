# Презентация для портфолио — Грузоперевозки72

## Быстрый старт

Откройте в браузере:

```
docs/portfolio/presentation.html
```

Или двойной клик по файлу в Finder.

## Навигация

| Действие | Клавиша |
|----------|---------|
| Следующий слайд | `→` `Пробел` `Page Down` |
| Предыдущий слайд | `←` `Page Up` |
| Сохранить как PDF | `P` или **Файл → Печать → Сохранить как PDF** |

## Содержание (12 слайдов)

1. Титул — название, стек, платформы
2. Проблема и решение
3. Роли пользователей
4. Ключевые функции (поиск, чаты, финансы…)
5. Сценарии сделок
6. Мобильное приложение (Flutter)
7. Backend и админка (обзор)
8. **Веб-админка** — статистика, рассылка, поддержка, модерация
9. Технические решения
10. Экраны и модули
11. Результат для бизнеса и портфолио
12. Финальный слайд

## Экспорт для Behance / LinkedIn

1. Откройте `presentation.html` в Chrome
2. `Cmd+P` → «Сохранить как PDF»
3. Включите «Фоновая графика»
4. Ориентация: альбомная или книжная (слайды адаптивные)
