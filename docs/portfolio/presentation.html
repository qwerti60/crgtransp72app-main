Грузоперевозки72

Маркетплейс грузоперевозок и спецтехники для Тюмени и Тюменской области. Мобильное приложение для заказчиков и исполнителей с поиском, сделками, чатами и финансами.

Flutter 6.0.0 PHP REST API Firebase Push iOS + Android Админ-панель

Проблема и решение

⚠️

Было

  • Десятки звонков и чатов в разных мессенджерах
  • Нет единого рейтинга и истории сделок
  • Сложно найти технику по параметрам и городу
  • Непрозрачные условия и комиссии
✅

Стало

  • Одна площадка: поиск → отклик → сделка → отзыв
  • Две роли в одном аккаунте (заказчик / исполнитель)
  • Умный поиск с счётчиками заявок по городу
  • Встроенные чаты, push-уведомления, раздел финансов

Роли пользователей

🚛 Заказчик

  • Каталог услуг: газели, фуры, краны, экскаваторы, грузчики
  • Поиск исполнителей по городу и параметрам
  • Публикация заявок и приём предложений
  • Таймер выполнения заказа, чат, отзывы

👷 Исполнитель

  • Размещение объявлений о технике за 2 минуты
  • Поиск заявок заказчиков в реальном времени
  • Отклики, принятие заказов, выполнение
  • Финансы: история заказов и выплат

Один пользователь может быть заказчиком и исполнителем одновременно — данные изолированы по контексту сделки.

Ключевые функции

🔍

Поиск

Гибкий поиск supply/demand, счётчики «(N)» по услугам и городам, сортировка по наличию заявок.

💬

Чаты

Переписка по сделке, чат техподдержки 24/7, push о новых сообщениях.

💰

Финансы

Раздел для исполнителей: учёт заказов, комиссии, история начислений.

⭐

Рейтинги

Взаимные отзывы после завершения заказа, рейтинг в профиле.

🔔

Push

Firebase Cloud Messaging: статусы заказов, отклики, начало выполнения.

⏱️

Сделки

Два сценария matching, таймер выполнения, контроль статусов в реальном времени.

Как работает сделка

Сценарий 1: исполнитель → заявка заказчика

Отклик исполнителя → Принятие заказчиком → Начало выполнения → Таймер + чат → Отзывы

Сценарий 2: заказчик → объявление исполнителя

Предложение заказа → Принятие исполнителем → Выполнение → Завершение → Повторный заказ возможен

Технические решения

Поиск и счётчики

  • Гибридный подсчёт demand: GROUP BY + отдельная логика для грузчиков
  • Единые SQL-фрагменты visibility (supply / demand)
  • API search_order_counts.php + UI-подсказки «(N)» в Flutter

Безопасность данных

  • Фильтр «не показывать свои объявления в чужой роли»
  • JWT-сессии, проверка viewer на стороне API
  • Разделение сценариев сделки по deal_source

CI/CD

  • Codemagic: сборка IPA, TestFlight
  • Gradle release AAB для Google Play
  • Автоподпись iOS (App Store Connect API)

Документация

  • 12+ markdown-гайдов: сделки, поиск, чаты, сценарии
  • Smoke-скрипты для API
  • Карта экранов и веток навигации
